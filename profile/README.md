Blazemap connects community observations, satellite indications, weather context, and structured analysis to support informed human review.

## Repositories

| Repository | Purpose | Stack |
| --- | --- | --- |
| [Blazemap-FE](https://github.com/Blazemap/Blazemap-FE) | Public website and account interface | React, TypeScript, Vite |
| [Blazemap-BE](https://github.com/Blazemap/Blazemap-BE) | Application API, authentication, and data | Express, Prisma, PostgreSQL |
| [Blazemap-AI](https://github.com/Blazemap/Blazemap-AI) | Internal decision-support analysis | Python, FastAPI, Pydantic |

## Approach

Observations, satellite hotspots, and AI outputs are not fire confirmations. Verification and operational decisions remain with authorized people.
